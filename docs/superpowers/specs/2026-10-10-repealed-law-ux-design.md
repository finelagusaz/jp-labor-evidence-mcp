# 廃止された法令の扱い — 設計メモ

- 日付: 2026-10-10
- ステータス: **実装済み（0.16.0）**
- 発端: [2026-07-13-egov-revision-version-info-design.md](2026-07-13-egov-revision-version-info-design.md) §2 の非目標「廃止法令のフル UX（廃止日・後継法・時点法令の本文取得など）」

## 1. 現状

- `get_article` で廃止された法令を引くと、`version_info` が「現行版の施行日 2026-10-01」と書いていた。e-Gov は廃止の版の施行日の項目に廃止日を入れるので、廃止日が「現行版の施行日」に化けていた
- `resolve_law` は、同じ題名の旧法（廃止）と新法がある日本学術会議法で `ambiguous` を返し、どちらが廃止されたかを示さなかった。`search_law` も廃止の状態を載せなかった
- 失効（`Expire`）・効力の喪失（`LossOfEffectiveness`）の法令も「この法令は廃止されています」と警告していた。e-Gov はこれらの法令でも `current_revision_status` を `Repeal` にするのに、`Repeal` の判定を先に評価していたため。spec §5.3 の「`repeal_status` を優先評価」と食い違っていた

## 2. 一次証拠（2026-10-10 に live で確認）

- 日本学術会議法（`323AC0000000121`）は 2026-10-01 に廃止。最後の版は `current_revision_status: Repeal`・`repeal_status: Repeal`・`repeal_date: 2026-10-01`・`amendment_enforcement_date: 2026-10-01`。`amendment_law_*` は廃止した法令（令和七年法律第七十号「日本学術会議法」、`507AC0000000070`）で、本文は廃止時点の条文を返す
- 国税犯則取締法（`133AC0000000067`）を廃止したのは一部改正法（平成二十九年法律第四号「所得税法等の一部を改正する等の法律」、`429AC0000000004`）。`/law_data/429AC0000000004` は 404。新しい日本学術会議法 `507AC0000000070` は 200。廃止した法令は後継の法令とは限らず、本文が取れるとも限らない
- `/laws?law_title=日本学術会議法`（`repeal_status` の指定なし）は旧法と新法の両方を返す。検索は既定で廃止された法令を含む。`revision_info` / `current_revision_info` に `repeal_status`・`repeal_date` がある
- 失効（官吏服務紀律 `120IO0000000039`）・効力の喪失（昭和十九年法律第四号 `319AC0000000004`）も `repeal_date` を持ち、`current_revision_status` は `Repeal`
- 廃止前の最後の施行版（`323AC0000000121_20051001_416AC0000000029`）は 0.14.0 の版の指定で取れる

## 3. 決定

| 論点 | 決定 | 理由 |
|---|---|---|
| `version_info` | 廃止・失効の法令は施行日の代わりに「廃止日／失効日／効力を失った日 X（和暦）　※本文は廃止時点の条文で、現に効力を有しません」。判定は警告と同じ複合トリガ。未施行の版（廃止予定を含む）は従来どおり施行予定日 | 「現行版の施行日」は誤り。「法令全体の現行版を指し…」の hedge は廃止された法令には当たらない。廃止予定の版はまだ施行されていない |
| 日付 | `repeal_date`、無ければ施行日の項目 | 調べた範囲では両者は一致した |
| `revision_metadata` | `repeal_date`（＋和暦）、`amendment_law_id` を追加 | 廃止日を機械可読に。廃止された法令では `amendment_law_id` が廃止した法令の ID |
| 警告文 | `repeal_status` を先に評価（Expire・LossOfEffectiveness・Suspend → Repeal）。廃止は「廃止した法令は「題名」（法令番号）です」を添え、「resolve_law で題名から探せます」と案内。効力の喪失にも日付を書く | §1 の食い違いの解消。廃止した法令を後継とは呼ばない、本文が取れるとも言わない（§2 の 404） |
| `resolve_law` | e-Gov 検索で補完した候補に `repeal_status`・`repeal_date`（＋和暦）。完全一致の候補のうち現行のものが 1 つで、廃止された候補もあれば、現行のものに解決（`resolved`）し、廃止された候補は後ろに残して `REPEALED_LAW_CANDIDATE` で知らせる。現行の候補が複数・0 なら判定は従来どおりで、警告だけ足す | 社労士が題名で引くのはほぼ現行の法令。廃止された候補を消さないので廃止前の条文にも辿れる。`resolved` で候補が 2 つになるのは、この場合だけ |
| `search_law` | upstream 検索の結果に `repeal_status`・`repeal_date`（＋和暦）。含まれれば `REPEALED_LAW_IN_RESULTS`。並び順は e-Gov のまま | 検索は網羅が目的なので除かない |
| 内部索引の経路 | 対象外 | 内蔵の 40 法令はいずれも廃止されていない（`npm run verify:egov` で現行と照合している） |
| 本文に添える文言 | text の見出しに「（廃止: 2026-10-01（令和8年10月1日））」 | LLM は text も読む |

**残すもの**: 廃止前の最後の施行版を版の ID で引くと「この版は過去の施行版であり…より新しい施行版が存在します」と警告する。より新しい版は廃止の版だが、文は誤りではないので変えない。

## 4. 検証

- 単体: `version_info` の廃止・失効・効力の喪失、`current_revision_status` だけが Repeal、未施行の廃止予定の版、`revision_metadata` の追加項目、警告（廃止した法令・失効と効力の喪失の文）、`resolve_law`（現行と廃止・廃止のみ・現行が複数）、`search_law` の廃止の状態と警告
- 結合（fixture は live の日本学術会議法（旧法）から第1条・第2条を切り出し）: `get_article`
- live（2026-10-10）: §2 の各法令。`resolve_law("日本学術会議法")` が新法 `507AC0000000070` に解決し、旧法を後ろに残すこと。労働基準法の解決は変わらないこと
