# 共通見出し（common_caption）— 設計メモ

- 日付: 2026-10-07
- ステータス: **実装済み（0.10.0）**
- 関連: 条見出しの扱い（0.8.1〜0.8.2、CHANGELOG）

## 1. 動機

法令では、連続する条をまとめる見出し（共通見出し）は最初の条にだけ付き、後続の条には付かない。労基法 第32条の2〜の5 は第32条の「（労働時間）」の下にあるが、`get_article` で第32条の2 を引いても主題がわからず、`get_evidence_bundle` も条番号と法令名だけで通達を探していた。

## 2. 一次証拠（2026-10-06 取得の live `law_data`、登録 40 法令）

本則で自分の見出しを持たない条は 1,020 条。

| 分類 | 条数 | 例 |
|---|---|---|
| 同じ章・節の中で、直前に見出しのある条があり、枝番号の関係 | 158 | 労基法 第32条の2 ← 第32条（労働時間） |
| 同じ章・節の中で、直前に見出しのある条があり、番号が別 | 207 | 労基法 第10〜12条 ← 第9条（定義）、第66条 ← 第65条（産前産後） |
| 章・節の先頭など、直前に見出しのある条が無い | 565 | 労基法 第42条（第5章の先頭）。見出しを持たない法令（労基則・労災保険法・労調法）を含む |
| 「削除」の条 | 90 | — |

e-Gov の XML には「この条は共通見出しの下にある」という印が無い。

## 3. 決定

| 論点 | 決定 | 理由 |
|---|---|---|
| 推論の規則 | 自分の見出しを持たない本則の条は、同じ親（章・節）の中で直前の見出しを持つ条の見出しを引き継ぐ。親をまたがない。「削除」の条と附則には付けない | 法令の書き方の約束と一致する（上の例はいずれも正しい組み合わせ）。章の先頭の条や見出しの無い法令には何も付かない |
| 出し方 | 別フィールド `common_caption: { caption, from_article }`（`get_article` の `data`、`get_evidence_bundle` の `primary_evidence`）。`body` には混ぜない（user 決定 2026-10-07） | 推論であり、一次情報である本文と混ぜない |
| 検索 | `get_evidence_bundle` で、自分の見出しが無い条は共通見出しを関連通達の検索と順位づけに使う（user 決定） | 共通見出しはその条の主題を表す |
| 対象外 | `diff_revision`、deprecated の `get_law` | 必要になったら同じ `commonCaption` を使える |

## 4. 検証

- 登録 40 法令の本則 5,576 条で `common_caption` が付くのは 365 条（§2 の 158 + 207 と一致）
- テスト: 枝番号・番号が別・自分の見出しあり・章の先頭（前の章の見出しを引き継がない）・項だけの取得・「削除」の条・附則
